Installieren

  1. Datei oben herunterladen und öffnen.
  2. Android fragt einmal, ob der Browser Apps installieren darf: Zulassen und zurück.
  3. Auf Installieren tippen.

Neu auf einem Gerät? Danach Barcode Buddy (QR-Code unter „API → Add mobile app“) und Grocy (Adresse und API-Schlüssel in den Einstellungen) koppeln.
Über eine vorhandene Installation lässt sich die Datei direkt drüberspielen, Einstellungen bleiben erhalten.

Hinweise

  • Diese Seite ist nur im Heimnetz oder über Tailscale erreichbar.
  • Updates holt die App selbst: Menü → „Nach Updates suchen“.
  • Die Uhr-App steckt in der Handy-App: Menü → „Uhr-App aktualisieren“.
